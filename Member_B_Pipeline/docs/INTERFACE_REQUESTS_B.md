## B → A assumptions that are *not* requests

* B never writes to A's `entries`/`events` tables except R9 (user creation).
* B never decides allocation: the gate only returns a weight; a weight never changes who
  can enter, only draw odds.
* The decision log (`defence.decisions`) is analytics: written asynchronously in batches,
  loss on crash is acceptable.
